## 扱う課題

プログラミングサークル Horizon（龍谷大学・瀬田／深草）の内部課題。

> 瀬田と深草の2拠点に分かれて活動しているため、別キャンパスのメンバーとは
> 名前を知っているだけで一度も話したことがなく、関わる相手がいつもの数人に固定されている。

解決策は「メンバーカード → AIがまだ話していない相手を1人選ぶ → 共通点・今日できる接点・一言目 → 『話した』を記録」。
詳細は [壁打ちメモ](../01_アイデア・壁打ち/2026-08-06_Horizonの2キャンパス間の関係を作るアプリ.md) と
[MVP要件定義](../02_要件定義/Horizon_2キャンパス間の関係_MVP要件定義.md) を参照。

## 当日に必ず埋めるもの

評価基準①が「一次情報の強さ」なので、次は実測・実聴の値で埋める。
**このプロダクトの一次情報は、その場で数えられるのが強み。**

- **名簿で数える**：メンバー全員について「話したことがある／名前だけ知っている／知らない」を
  分類し、「まだ話したことがない人」の割合を出す。瀬田・深草それぞれで分ける
- **Discordで数える**：直近1か月に発言した人が全体の何割か
- **聞き取り**：別キャンパスの人と話したことがある人に、そのきっかけを聞く
- 瀬田⇄深草の実際の所要時間（片道）
- 記入者名、記入者②〜⑥のシート
- プロダクト名の確定
- 公開URL、GitHubリポジトリURL、デプロイURL
- 各Stepの判定チェックボックスと提出チェックリスト
