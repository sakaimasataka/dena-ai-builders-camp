# MVP要件定義｜つながり帳 ―出会った人を、次のつながりへ―

作成日：2026年8月6日（最終版）  
用途：AI Builders Camp 京都Kick Off でのMVP制作・要件共有  
団体：プログラミングサークル Horizon（龍谷大学・瀬田／深草）

## 1. プロダクト概要

### 一言で表すと

> 出会った人を「どこで会って、何が共通か」ごと記録し、
> 共通の授業・空きコマ・イベントから次に会えるきっかけを教えてくれる、Horizon部員のつながり帳。

### 解決したい課題（ワークシートStep2で確定）

Horizonの新歓や初回の活動で、新入部員と既存部員がInstagram・LINE・Discordを交換しても、
相手を思い出す文脈と次に関わるきっかけが残らず、交換したはずの関係がそのまま立ち消えている。

解消する原因（Step4で1つに絞った）：
**相手が今何をやっているかが見えないので、共通点が分からず、話しかける材料がない。**

> 対象はHorizonの部員のみ。大学全体・他サークルへの展開は今回やらない。

### 提供価値

1. **思い出せる**：誰と、どこで出会ったか（例：Horizon新歓）が自動で残る
2. **共通点が分かる**：共通授業・興味・サークル・イベントがタグで見える
3. **次に会えるきっかけが分かる**：共通の空きコマ・授業・イベントをシステムが照合して提示する
4. **行動に移せる**：テンプレートの誘い文で、そのまま誘って予定にできる

## 2. 設計上の確定事項

- **交換はURL**：「つながる」ボタン → 交換用URLを共有 → 開くと相互に出会いカードが生成される。
  QRカメラ読み取りは作らない（QR画像の表示は余裕があれば）
- **照合はシステム（ルールベース）**：共通授業・共通の空きコマ・共通イベントの突き合わせは条件一致で実装する。
  誘い文はテンプレートへの差し込みで生成する。**MVPにAIは使わない**
- AIの出番は次の段階：自由記述の興味・活動履歴からの共通点発見、相手や場面に合わせた誘い文の調整

## 3. 想定ユーザー

- 主ユーザー：Horizonの新入部員（新歓・初回活動で多くの先輩・同期と連絡先を交換する側）
- 副ユーザー：新入部員を迎える既存部員、部内の関係を広げたい運営

## 4. 成功の定義

### 最重要指標

**交換した相手と、実際に次の接点（予定・会話）が生まれた数。**

### モックのデモ成功条件

> URL交換 → 出会いカードを確認 → つながり帳で共通点を見る → 「次に会えそう」→ 誘い文を送る → 承認 → 一緒にする予定

この一連を3分ピッチ内で迷わず完了できること。

## 5. 画面構成（UIモック準拠）

下部4タブ：**ホーム／つながり帳／予定／プロフィール**。中心は「つながり帳」タブ。

### ①つながり帳（中心画面）

上から順に1画面に縦積みする。

1. ヘッダー：「つながり帳｜出会った人を、次のつながりへ」＋通知アイコン
2. 検索バー：名前・授業・イベントで検索
3. フィルタチップ：最近会った／同じ授業／サークル／Horizon
4. **最近つながった人**（大カード）：写真、名前・学部学年、「Horizon新歓で出会いました」、
   共通点タグ（例：心理学概論／軽音に興味）、「プロフィールを見る」、
   「話したこと：軽音と大学生活」の自分用メモ＋編集
5. **みんなのプロフィール**（小カードのグリッド）：名前・学部学年・共通点タグ1つ
6. **次に会えそう**：「水曜3限、ミサキさんも空きコマ」＋（2限 心理学概論 → 3限 空きコマ）＋
   「一緒にどこか行ってみる？」ボタン
7. 右下フローティング「つながる」ボタン（交換用URLの共有）

### ②出会いカード詳細

プロフィール、出会った文脈、共通授業・共通の空きコマ（相手が時間割公開の場合のみ）、
「話したこと」メモの編集（相手には見えない）。

### ③次に会えそう → 予定成立

照合結果 → 誘い文（テンプレ差し込み、編集可）→ 送る → 相手の承認 → 「一緒にする予定」として表示。

補助（静的でよい）：ホーム＝自分の時間割＋Horizonイベント（未参加グレー／参加で色付き）、
予定＝成立した予定の一覧、プロフィール＝自分の情報＋時間割公開ON/OFF。

## 6. 機能要件

P0＝MVP必須、P1＝余裕があれば、P2＝将来。

### 6.1 プロフィール・交換

| ID | 優先度 | 要件 |
| --- | --- | --- |
| PR-01 | P0 | ニックネーム、学部、学年、キャンパス、興味/得意な技術を登録・表示できる |
| PR-02 | P0 | 「つながる」ボタンから自分の交換用URLを共有（コピー）できる |
| PR-03 | P0 | 交換用URLを開くと、相互に出会いカードが自動生成される |
| PR-04 | P0 | 出会いカードに交換日時と出会った場面（例：Horizon新歓）が残る |
| PR-05 | P1 | 出会った場面を自動で決められない場合、候補から1タップで選べる |
| PR-06 | P1 | QRコード画像の表示 |
| PR-07 | P2 | QRカメラ読み取り、本人確認 |

### 6.2 つながり帳

| ID | 優先度 | 要件 |
| --- | --- | --- |
| TB-01 | P0 | つながった部員をカード一覧で表示する（最近つながった人＋みんなのプロフィール） |
| TB-02 | P0 | 各カードに共通点タグ（共通授業・興味・サークル・イベント）を表示する |
| TB-03 | P0 | 名前・授業・イベントで検索できる |
| TB-04 | P0 | フィルタチップ（最近会った／同じ授業／サークル／Horizon）で絞り込める |
| TB-05 | P0 | 「話したこと」の自分用メモを記録・編集できる（相手には見えない） |
| TB-06 | P1 | カードの並びを「最近つながった順」にする |

### 6.3 時間割・イベント

| ID | 優先度 | 要件 |
| --- | --- | --- |
| TT-01 | P0 | 自分の時間割を登録・表示できる |
| TT-02 | P0 | 時間割の公開ON/OFFを本人が選べる |
| TT-03 | P0 | 相手が公開している場合のみ、共通授業・共通の空きコマを表示する |
| EV-01 | P0 | Horizonのイベントを表示し、未参加はグレー、参加表明で色付きにする |
| EV-02 | P1 | 同じイベントへの参加予定者が分かる |

### 6.4 照合と予定（システム／ルールベース）

| ID | 優先度 | 要件 |
| --- | --- | --- |
| MT-01 | P0 | 共通授業・共通の空きコマ・共通イベントを条件一致で照合し、「次に会えそう」を提示する |
| MT-02 | P0 | 照合の根拠を表示する（例：2限 心理学概論 → 3限 お互い空きコマ） |
| MT-03 | P0 | テンプレートに名前・授業名・時間を差し込んだ誘い文を生成し、本人が編集できる |
| MT-04 | P0 | 非公開の時間割・予定は照合結果の表示に使わない |
| PL-01 | P0 | 誘いを送り、相手が承認すると「一緒にする予定」として両方に表示される |
| PL-02 | P1 | 予定を辞退できる（辞退の記録は相手に晒さない） |

## 7. システムがしてはいけないこと

- 非公開の時間割・予定を相手に見せる、照合結果に使う
- 登録されていない情報から共通点を作る
- 本人の確認なしに誘いを送る
- 相性スコアや順位を表示する
- 恋愛的な関係を示唆する文面・表示
- 「話したこと」メモを相手に見せる

## 8. 非機能要件

- スマートフォン縦画面基準（幅375〜430px）。白基調＋藍色、ミント／コーラルのアクセント（UIモック準拠）
- 交換から出会いカード表示まで、目標30秒以内
- デモは固定データで動かし、通信・生成待ちによる事故を避ける
- 状態（未参加／参加、公開／非公開）は色だけでなく文字でも示す

## 9. MVPの対象外（やらないことリスト）

- QRコードのカメラ読み取り
- AIによる誘い文の自由生成・共通点の推論（テンプレとルール照合で代替）
- 「誘われてもよい時間」の設定、複数人の予定の自動調整
- 時間割の細かい公開範囲（今回は表示ON/OFFのみ）
- 大学公式システムとの連携、履修データの自動取り込み
- 本人確認・大学認証、ブロック／通報（画面に存在だけ示す）
- 現在地の共有、会話の録音・文字起こし
- 通知の個人最適化、Instagram / LINEへの共有
- 自動送信
- Horizon部員以外への展開
- ホーム／予定／プロフィールタブの作り込み

## 10. 受け入れ条件

- [ ] 交換用URLを開くと出会いカードが相互に生成される
- [ ] 出会った場面（Horizon新歓）と共通点タグが表示される
- [ ] つながり帳で検索・フィルタが動く
- [ ] 「話したこと」メモを編集でき、相手には見えない
- [ ] 相手の時間割は公開設定のときだけ共通授業・空きコマが出る
- [ ] 「次に会えそう」が根拠つきで表示される
- [ ] 誘い文を確認・編集して送れる
- [ ] 承認後に「一緒にする予定」が表示される
- [ ] 一連のデモが3分で通る

## 11. デモ用固定データ

- 自分：ハルト（経営学部1年・瀬田・Horizon新入部員）
- 最近つながった人：ミサキ（文学部1年、Horizon新歓で出会った、共通＝心理学概論・軽音に興味、時間割公開）
- みんなのプロフィール：タイチ（経済学部1年・統計学で一緒）、アヤカ（法学部1年・卓球サークル）、
  ソウタ（理学部1年・新入生交流会）、リコ（文学部1年・英語の授業）
- 次に会えそう：水曜 2限 心理学概論（共通）→ 3限 お互い空きコマ
- 誘い文テンプレ：「この前のHorizon新歓で話したハルトです！水曜の心理学概論のあと、3限空いてたら一緒に学食行かない？」
