### 前案1：初対面の学生を再会につなげるアプリ（8/5・大学全体対象）

- [壁打ちメモ](./2026-08-05_初対面の学生を再会につなげるアプリ.md)
- [MVP要件定義](./初対面の学生を再会につなげるアプリ_MVP要件定義.md)

大学生全般（新歓・時間割・大学イベント）を対象にした案。お題が「自分たちの団体が抱える課題」
であるため対象を差し替えたが、**この案の骨格（出会った文脈を残す→共通点から次の行動を作る）が
そのまま現行「つながり帳」の土台になっている**。

### 前案2：2キャンパス間の関係を作るアプリ「クロス」（8/6・Horizon対象）

- [壁打ちメモ](./2026-08-06_Horizonの2キャンパス間の関係を作るアプリ.md)
- [MVP要件定義](./Horizon_2キャンパス間の関係_MVP要件定義.md)

課題を「瀬田・深草の2拠点間の関係の薄さ」に置いた案。AIが「まだ話したことがない相手」を
1人選んで一言目を出す設計だった。課題をチームで「連絡先を交換しても文脈ときっかけが残らず
立ち消える」に確定した際に、前案1の骨格を直接Horizonへ移した「つながり帳」に置き換えた。
