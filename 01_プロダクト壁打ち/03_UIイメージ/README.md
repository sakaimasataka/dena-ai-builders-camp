# MVP UIイメージ

AI Builders Campのモック制作に向けた、方向性検討用の高精細UIイメージです。画像生成による参考案のため、実装時は文字、余白、遷移、公開範囲を要件定義に合わせて調整します。

## 画像一覧

1. [MVP全体フロー](./01_MVP全体フロー.png)  
   時間割ホーム、QR交換、出会いカード、AI提案、予定成立の5画面。

2. [時間割ホーム](./02_時間割ホーム.png)  
   授業、大学イベント、参加状態、QR導線、時間割の公開状態をまとめた案。

3. [出会いカード・AI提案](./03_出会いカード_AI提案.png)  
   出会ったきっかけ、共通点、公開中の時間割から、AIが次の行動と誘い文を提案する案。

## デザイン方針

- 白を基調に、濃い藍色を基本色、ミント色を共通点・参加状態、コーラル色を主要アクションに使う
- 新入生向けに親しみやすくしつつ、時間割と個人情報を扱うため軽すぎない印象にする
- 恋愛アプリに見えないよう、ハートや相性スコアを使わない
- AIはロボットを前面に出さず、共通情報を行動へ変える部分で示す
- 時間割は、本人が表示・非表示を選べることが分かる表示にする

## MVPとの境界

- `01_MVP全体フロー.png` の5画面をモックの中心とする
- `02_時間割ホーム.png` の「友達と重なる時間」は余裕があれば見せる機能であり、MVP必須ではない
- 「誘われてもよい時間」の設定や複数人の高度な自動調整は、このUI案には含めない
- AI提案は、公開されているプロフィール、時間割、授業、イベントだけを根拠にする

## 生成時のプロンプト概要

画像生成機能を使用し、次を固定して生成した。

- 用途：日本の大学新入生向けモバイルアプリの高精細UIモック
- 中心導線：時間割ホーム → QR交換 → 出会いカード → AI行動提案 → 共同予定成立
- 共通人物：文学部1年のミサキさん、軽音、新歓で出会った、心理学概論が共通
- 共通表現：白、藍色、ミント、コーラル、角丸カード、実用的なタップ領域
- 制約：恋愛表現なし、無関係なロゴなし、透かしなし、非公開情報を提案に利用しない
