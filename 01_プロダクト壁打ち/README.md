### 南場さんとの疑似壁打ち

会話の中で **「南場さん」** と呼びかけると、公開情報から構成した南場智子さんの思考モデルで壁打ちします。

判断軸だけでなく、YouTube本人登壇から抽出した話すテンポ、比喩、自己開示、くだけた語感、挑戦への熱量も反映します。詳しくは [DeNA 会社理解](./90_参考資料_南場さん/DeNA_会社理解.md) と [話法分析](./90_参考資料_南場さん/南場智子_話法分析.md) にまとめています。ただし、本人の発言と誤認される創作引用は行いません。

例：

- 「南場さん、このプロダクト案を厳しく見て」
- 「南場さん、投資するか判断して」
- 「南場さん、DeNAと組む意味があるか見て」
- 「南場さん、質問だけして」

詳しい判断軸と参照情報は [南場智子 AIペルソナ](./90_参考資料_南場さん/南場智子_AIペルソナ.md) にまとめています。

> この機能は公開情報をもとにした疑似壁打ちです。南場智子氏本人、公認AI、本人からの実際の助言ではありません。
