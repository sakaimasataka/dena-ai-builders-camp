## 扱う課題

プログラミングサークル Horizon の内部課題。

> 新歓で入会した1年生が、週1の対面もくもく会に数回来たあと来なくなる。  
> 来た時点で「今日の2時間で終わるゴール」が決まっておらず、手応えゼロで帰るため。

解決策は「冒頭に1行宣言 → AIが今日のゴール・相棒・声のかけ方を出す → 終了時に『できた』を1行記録」。
詳細は [壁打ちメモ](../01_アイデア・壁打ち/2026-08-06_Horizonのもくもく会で新入生の定着を作るアプリ.md) と
[MVP要件定義](../02_要件定義/Horizon_もくもく会_MVP要件定義.md) を参照。

## 当日に必ず埋めるもの

評価基準①が「一次情報の強さ」なので、次は実測・実聴の値で埋める。

- **出席の実数**：過去3回のもくもく会の出席者名を書き出し、新歓入会者のうち誰がいつから来ていないかを数える
- **離脱者への聞き取り**：来なくなった1年生2〜3人に、最後に来た日に何をしたか・できた実感があったか
- 大学名、記入者名
- 記入者②〜⑥のシート（各自の実体験、①と違う場面）
- プロダクト名の確定
- 公開URL、GitHubリポジトリURL、デプロイURL
- 各Stepの判定チェックボックスと提出チェックリスト
