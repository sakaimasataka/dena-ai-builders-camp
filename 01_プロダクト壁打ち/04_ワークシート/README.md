# 当日ワークシート

AI Builders Camp 京都Kick Off の公式ワークシート（配布された `.docx`）に、**つながり帳**の企画内容を記入した最終版です。

- [AI_Builders_Camp_KickOff_ワークシート_team-i.docx](./AI_Builders_Camp_KickOff_ワークシート_team-i.docx)

## 記入内容の骨子

- **課題（Step2）**：新歓や初回の活動で連絡先を交換しても、相手を思い出す文脈と次に関わるきっかけが残らず、関係が立ち消えている（Horizonの新入部員×既存部員）
- **今日解消する原因（Step4・1つに絞り済み）**：相手が今何をやっているかが見えず、共通点が分からず、話しかける材料がない
- **解決策（Step5）**：URL交換で出会いカードを自動生成 → システムが共通授業・空きコマ・イベントを照合 → 誘い文 → 予定成立。**AI不使用（テンプレ＋ルール照合）**
- **MVP（Step6）**：最小の1機能＝照合と誘い文の提示。画面3つ＝つながり帳／出会いカード詳細／次に会えそう→予定成立
- **要件定義（Step7）**：プロダクト名「つながり帳」。詳細は [つながり帳_MVP要件定義](../02_要件定義/つながり帳_MVP要件定義.md)

## 当日に必ず埋めるもの

- **一次情報の実測値**（Step1・Step3）：部員名簿×SNS交換履歴で「交換したのに関わりがない人数」、新入部員への聞き取り、Discord直近1か月の発言者数
- 記入者名、記入者②〜⑥のシート
- 公開URL、GitHubリポジトリURL、デプロイURL（Step9）
- 各Stepの判定チェックボックスと提出チェックリスト

## Step7-2以降の手順

1. このdocxをダウンロードしてClaude Codeに添付し、ワークシート内蔵のプロンプトで要件定義を整理
2. 返ってきた内容で「主要機能」欄を上書き
3. Step8の実装は、このリポジトリの [`mvp/index.html`](../../mvp/README.md) が先行実装としてそのまま使える
