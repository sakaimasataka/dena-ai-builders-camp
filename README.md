# つながり帳 ―出会った人を、次のつながりへ―

プログラミングサークル **Horizon**（龍谷大学・瀬田／深草、チーム team-i）が、
AI Builders Camp 京都Kick Offで作るプロダクトです。

## 課題

> Horizonの新歓や初回の活動で、新入部員と既存部員がInstagram・LINE・Discordを交換しても、
> 相手を思い出す文脈と次に関わるきっかけが残らず、交換したはずの関係がそのまま立ち消えている。

原因は、相手が今何をやっているかが見えず、共通点が分からず、話しかける材料がないこと。
SNSは「連絡できる状態」までしか作らない。

## プロダクト

- **URLで交換**すると、出会った場面（例：Horizon新歓）と共通点タグが入った「出会いカード」が自動で残る
- **つながり帳画面**：検索・フィルタ、最近つながった人、みんなのプロフィール、「次に会えそう」を1画面に
- **システム（ルールベース）が照合**：共通授業・共通の空きコマ・共通イベントから「次に会えそう」を根拠つきで提示
- テンプレ差し込みの**誘い文**を確認して送る → 相手の承認 → **「一緒にする予定」** に
- MVPにAIは使わない。AIは次の段階で「自由記述からの共通点発見」と「誘い文の調整」に使う

## MVPを動かす

`mvp/index.html` をブラウザで開くだけ（ビルド・サーバー・通信すべて不要）。
スマホ縦画面基準のUIなので、PCではデバイスモード（幅390px程度）推奨。
