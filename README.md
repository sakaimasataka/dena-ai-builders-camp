# DeNA AI Builders Camp｜プロダクト企画

プログラミングサークル **Horizon**（team-i）が、AI Builders Camp 京都Kick Offで作るプロダクトの企画資料です。

## プロダクトの目標

> 週1のもくもく会で、来た人が「今日できたこと」と「一緒にやった人」を1つずつ持って帰れるようにする。

新歓で入会した1年生が、もくもく会に数回来たあと来なくなる。
来た時点で「今日の2時間で終わるゴール」が決まっておらず、環境構築や入門記事の検索で時間が終わり、
何も持ち帰れないためです。

冒頭に「今日やること」を1行だけ宣言すると、AIがその場の参加者の情報をもとに
**今日のゴール（2時間サイズ）・今日の相棒・声のかけ方**を出します。
終了5分前に「できた」を1行記録し、次回の冒頭に持ち越します。

## 現在の状態

AI Builders Camp 京都Kick Off 当日。ワークシートは記入済みで、一次情報の実測値と実装が残っています。

はじめは大学生全般を対象にした「初対面の学生を再会につなげるアプリ」で進めていましたが、
お題が「自分たちの団体が抱える課題」であるため、Horizon内部の課題へ差し替えました。
前案の骨格（文脈を残す → 共通点から次の行動を作る → 実際に一緒にやる）はそのまま流用しています。
前案の資料も参照用に残しています。
