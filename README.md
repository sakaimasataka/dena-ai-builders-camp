# DeNA AI Builders Camp｜プロダクト企画

大学生が新歓や授業で出会った相手を思い出し、共通の授業・時間割・大学イベントをもとに、次に一緒に行動する予定を作れるアプリの企画資料です。

## プロダクトの目標

> 初対面の「知り合い」を、実際に一緒に行動する「友達」へ変える。

QR交換を入口に、出会った文脈、プロフィール、公開された時間割、共通授業、参加イベントを整理します。AIはそれらを根拠に、一緒にできる行動と自然な誘い文を提案します。
