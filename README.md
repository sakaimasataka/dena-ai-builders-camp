# DeNA AI Builders Camp｜プロダクト企画

プログラミングサークル **Horizon**（龍谷大学・瀬田／深草、team-i）が、
AI Builders Camp 京都Kick Offで作るプロダクトの企画資料です。

## プロダクトの目標

> 同じサークルなのに、まだ一度も話したことがない人との最初の1回をつくる。

Horizonは瀬田と深草の2拠点で活動しています。別キャンパスのメンバーとは
名前を知っているだけで一度も話したことがなく、関わる相手がいつもの数人に固定されています。

メンバーカード（キャンパス・今つくっているもの・得意・今詰まっていること）をもとに、
AIが**まだ話したことがない相手**の中から共通点を根拠に1人を選び、
**今日できる小さな接点**と**そのまま送れる一言目**を出します。

接点はオンラインで完結するサイズに限定するので、キャンパスが離れていることが不利になりません。
仲のいい人をさらに推す既存のSNSとは逆に、まだ関わっていない人を優先して出します。

## 現在の状態

AI Builders Camp 京都Kick Off 当日。ワークシートは記入済みで、一次情報の実測値と実装が残っています。

はじめは大学生全般を対象にした「初対面の学生を再会につなげるアプリ」で進めていましたが、
お題が「自分たちの団体が抱える課題」であるため、Horizon内部の課題へ差し替えました。
前案の骨格（相手の文脈を残す → 共通点から次の行動を作る → 実際に一緒にやる）はそのまま流用しています。
違いは、前案が「二回目の行動」を作るのに対し、本案は「一回目の接点」を作ることです。
前案の資料も参照用に残しています。
