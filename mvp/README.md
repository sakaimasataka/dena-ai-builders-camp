# つながり帳 MVP

**出会った人を、次のつながりへ。** Horizon部員向けのつながり帳アプリのMVPです。

## 動かし方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー・通信すべて不要）。
スマートフォン縦画面基準のUIなので、PCではブラウザのデバイスモード（幅390px程度）推奨。

```bash
# ローカルサーバーを使う場合
python3 -m http.server 8000
# → http://localhost:8000/mvp/
```

## 3分デモの手順

1. **つながり帳**タブ：検索・フィルタ（同じ授業／Horizonなど）を触って見せる
2. 「最近つながった人」ミサキさんのカード：**「Horizon新歓で出会いました」**（出会った文脈）と共通点タグ、
   「話したこと」メモの編集（自分にだけ表示）を見せる
3. 右下**「つながる」**：交換用URLをコピー →「（デモ）相手がURLを開いた体験を見る」→ ケンタさんの出会いカードが自動生成される
4. **「次に会えそう」**：水曜2限 心理学概論 → 3限 お互い空きコマ、という根拠つきの照合結果
5. 「一緒にどこか行ってみる？」→ テンプレ差し込みの誘い文を確認して送る → ミサキさんが承認 →
   **予定タブに「一緒にする予定」が追加される**（通知ベルにも赤ドット）
6. ホームタブ：時間割の共通コマ（ミント色）、Horizonイベントの参加表明（グレー→色付き）
7. プロフィールタブ：時間割の公開ON/OFF

## 実装のポイント（要件定義との対応）

- 交換は**URL**（QRカメラ読み取りなし）— PR-02/03
- 照合は**ルールベース**（共通授業・空きコマ・イベントの条件一致）、誘い文は**テンプレ差し込み** — MT-01〜03、**AI不使用**
- メモは自分にだけ表示 — TB-05
- 非公開の時間割は共通コマを表示しない（タイチさん等の詳細で確認可） — MT-04
- 送信前に必ず本人が文面を確認 — 自動送信なし
- データはすべて固定のデモデータ＋localStorage（デモ事故防止）
